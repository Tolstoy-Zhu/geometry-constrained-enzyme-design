# AquaEsterNet 接入 ZhangBioLab 在线任务的实施计划

2026-11-05 · 方案稿，待开发

在 AquaEsterNet 工作台选定一条亲本序列，填写底物、配体和保留位点，提交至 ZhangBioLab。研究者随后可以在同一工作台查看进度、阅读警告、下载设计结果，并选取序列进入已有的 AlphaFold2 和 TM-align 结构复核流程。首版接入 ZhangBioLab 的 **Auto Pipeline**。序列设计与性质预测由远端执行，AquaEsterNet 负责输入核对、任务管理和结果解释。

## 在线接口与使用范围

2026-11-05 核对了 ZhangBioLab 自动提交页、任务状态页的公开前端，以及项目中保存的一次历史任务回执。下列接口属于网页正在使用的接口，尚无已确认的版本或兼容期承诺。服务地址应可配置，调用集中在一个客户端中。[自动提交页](http://8.219.252.8/submit.html) · [平台说明](http://8.219.252.8/help.html)

| 操作 | 可核对的行为 | AquaEsterNet 的实现要求 |
|---|---|---|
| 提交一次任务 | `POST /api/submit` 接受 FASTA、底物、配体、固定位置、保守性阈值及权重，成功响应含 `task_id` | 提交前预览外发内容并确认。先保存本次提交记录，收到回执后立即绑定远端 ID。 |
| 查看任务 | `GET /api/tasks/{task_id}` 可返回 `status`、`current_stage`、`progress`、`warning`、`error`、`results` 和 `download_url` | 只按本地已登记或用户明确提供的任务 ID 查询。保存原始状态，查询失败时显示上次成功查询时间。 |
| 取回结果 | 完成回执可带结果列表和结果包下载地址 | 按服务返回的 `download_url` 下载，核对来源并归档。结果包暂缺或损坏时允许单独重试下载。 |

本次核对的服务入口使用 HTTP，首轮联调采用公开的 8HFW 序列。开放未公开序列提交前，需配置并核验服务方的加密访问入口及数据处理条件。GitHub 上的测试使用合成回执和最小示例包，真实任务 ID 和结果包保存在项目运行目录。

## 开发顺序与验收

| 阶段 | 工作内容 | 验收条件 |
|---|---|---|
| 1 · 新建与提交 | 工作台增加“ZhangBioLab 在线任务”。支持从 StructMine 候选表选择亲本，或粘贴单条 FASTA。预览序列、底物与配体 SMILES、固定位置和权重，核对各组权重之和。保存亲本来源、序列哈希、请求参数和回执。 | 用 8HFW A 链 12–294 的 283 aa 构建核查编号。PDB 的 Ser111、Asp241、His274 应对应输入序列的 S100、D230、H263。其他亲本重新映射，缺失或有歧义的位置提示人工核对。同一次点击或页面刷新只产生一笔提交。 |
| 2 · 查看与恢复 | 提供本地任务列表和独立详情页，显示远端 ID、当前阶段、进度、最后更新时间、警告及错误。页面打开时逐渐延长查询间隔，重新打开工作台后按已有 ID 继续。 | 覆盖排队、运行、完成、失败、取消及暂时断网。进度达到 100% 仍以服务端终态为准。若提交后超时且没有收到 ID，标记“提交状态待核对”，允许补录 ID，避免自动重投消耗第二份计算资源。 |
| 3 · 下载与解析 | 将原始结果包、文件校验值和解析后的候选表归入同一任务。按候选标识和序列哈希关联 FASTA、性质预测及结构文件。列表保留服务端排名，区分原始值、有效值和缺失原因。 | 重复下载或导入同一结果包不会新增重复候选。缺列、部分结果和损坏压缩包都能给出具体原因。只将序列确属该设计的坐标关联给候选。将 `RMSD=999.9、pLDDT=0、pTM=0` 的已知占位组合保留在原始记录，有效结构指标留空。 |
| 4 · 进入结构复核 | 在设计结果页选择候选，交给已有的 AF2 单体预测和亲本–设计 TM-align 比对。关联原任务、候选、预测模型和比对结果。展示结构置信度、双向 TM-score、催化残基身份及侧链距离。 | 用亲本、一个近亲本少突变设计及一条缺少结构的设计检查流程。近亲本设计走成对比较，避免被天然同源物检索中的 95% 序列一致性上限误剔除。结构记录可以逐条回到输入设计序列。 |

## 评分与实验记录

外部可溶性、热稳定性、底物匹配及动力学预测分别展示，保留原模型名称、字段和原始尺度。只在模型任务、单位和变换有依据时标注物理量。服务端综合分和本地 WASE-screen 各保留来源与版本。辛酸乙酯生成速率、对应水解速率及 S/H 由实验记录给出，并保留测定条件。远端作业完成、获得设计结构和获得酶学实测值在界面中分别标记。

## 首版完成的判断

先用离线回执覆盖重复点击、提交响应丢失、断网恢复、任务失败和结构指标缺失。随后以公开 Bur01 构建、辛酸和乙醇在服务可用时完成一次用户确认的真实任务。验收者应能在 AquaEsterNet 中提交、关闭并重新打开工作台、找到同一任务、下载并查看候选，且在全过程中只生成一个远端任务。在线提交与结果查看通过验收后，再接通阶段 4 的本地计算入口。
