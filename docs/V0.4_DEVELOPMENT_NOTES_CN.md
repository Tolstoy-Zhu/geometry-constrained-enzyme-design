# AquaEsterNet-StructMine v0.4 开发说明

v0.4 在 v0.3 结构挖掘与本地 AlphaFold2 流程上增加 NCBI NR 序列扩增、NR 最近邻新颖性审计和完整 NR 服务器作业包。

已完成：

- MMseqs2 两轮搜索、2,500 命中上限、`search-type=1` 和 50% 聚类预设。
- Foldseek 目标序列种子、accession/序列 SHA-256 去重和三催化位点映射。
- NCBI 远程 BLAST 的邮箱、逐次确认、串行轮询、重试、缓存和批量取序列。
- 无凭据 Bash/Slurm/PBS 完整 NR 作业包及安全导入。
- NR 候选到 AF2、再到结构挖掘的双向清单。
- 网页“NR挖掘”视图和 65 项隔离测试。
- NR 处理轨迹、4 张 `2880x1800` 桌面截图和 1 张 `780x1688` 移动截图；验证数据在界面中明确标识，采集后临时服务已关闭。
- MMseqs2 `18.8cc5c` 与 BLAST+ `2.17.0` 真实运行时诊断。

未完成的正式发布门槛：

- 真实本机 NCBI NR 命中子集需要用户逐次确认后执行。
- 至少一条真实 NR 候选需要完成 AF2 与结构复核。
- 完整 NR 需要在服务器/HPC 执行、导回并通过验收。

因此，本文件不是正式 `v0.4.0` Release Notes。开发分支可以推送，但不得合并、打标签或发布。
