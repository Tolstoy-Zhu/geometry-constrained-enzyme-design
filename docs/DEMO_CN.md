# Bur01 只读演示

## 启动和结束

1. 双击项目根目录 `start_demo.bat`。它读取既有项目Python环境，自动选择空闲端口，打开本机浏览器。
2. 演示完毕双击 `stop_demo.bat`。关闭浏览器不会自动结束本机服务。
3. 若需要导入自己的记录或运行挖掘，另开 `start_ui.bat`；结束完整工作台用 `stop_ui.bat`。

本轮不新增登录自启动、守护重启或公网通道。演示只监听127.0.0.1，其他电脑不能直接访问此地址。可在装有项目及依赖的电脑本地展示，或通过屏幕共享展示当前电脑。

## 演示顺序

| 步骤 | 可展示内容 | 如何表述 |
|---|---|---|
| 输入结构 | 8HFW:A、12–294、Ser111/Asp241/His274、旋转结构 | 这是公开的Bur01实验结构 |
| 候选筛选 | 真实Foldseek固定基准、阳/阴性、阈值排除原因 | 这是有运行编号的真实计算记录；不是现场重新跑库 |
| 结构比较 | TM-align叠合、qTM/tTM/RMSD、对齐条 | 结构相似性支持候选筛选，不能替代功能实验 |
| 评分解释 | 四部分分数、缺失项、催化几何、版本 | WASE-screen为透明预筛分，预测误差尚未估计 |
| 实验评估 | 模拟测量、重复汇总、误差、排序和Top-k | 这是模拟数据，展示将来如何回填实测结果 |

演示可以筛选、旋转和查看详情，没有生产任务提交、重新注释或生产结果修改入口。固定资料由 `data/demo/demo_manifest.json` 逐项SHA-256校验，内容变化或缺文件会明确报错。

## 离线范围

3Dmol 2.5.5代码、结构、计算摘要和模拟实验数据本地提供。演示启动及页面切换不调用WSL、GPU、外部预测或下载服务；网页3D渲染使用浏览器WebGL，这与运行AlphaFold GPU推理不同。仍需本机Python/Streamlit服务运行，不能把localhost地址当作静态HTML在另一台电脑直接打开。

## 位点查看

完整工作台“结构”页展开“底物与位点”，上传PDB/CIF/mmCIF并选择模型、蛋白链和已有配体。水与常见离子默认不选；其他非蛋白组分仅作为待辨认的配体/辅因子选项，并不自动证明其为反应底物。

默认4 Å重原子接触表可选行，与三维高亮联动；也可直接选择残基。导出保留模型、链、编号、插入码、结构哈希、距离参数、配体ID以及“保留/关注/排除”标记。SMILES为记录信息，未运行化学有效性或结合预测验证。没有配体坐标时仅保存信息，不生成虚构姿势。

## 命令行

```powershell
python -m bur01_structmine.cli demo
python -m bur01_structmine.cli demo --no-browser
python -m bur01_structmine.cli stop-demo
```

运行状态与服务日志仅写入 `.cache/demo_service/`。停止命令核对PID、随机服务标识和项目脚本，避免误杀其他程序。启动端口被占用时换用未指定端口的命令自动选择。
