# AquaEsterNet-StructMine v0.4 Development Notes

v0.4 extends the v0.3 structure-mining and local AlphaFold2 workflow with NCBI NR sequence expansion, nearest-neighbor novelty audit, and complete-NR server job packages.

Implemented:

- Fixed two-iteration MMseqs2 search, 2,500-hit limit, `search-type=1`, and 50% clustering.
- Foldseek target-sequence seeds, accession/sequence-SHA-256 deduplication, and three-site catalytic mapping.
- Contact email, per-request consent, serial polling, retry, cache, and batched sequence retrieval for NCBI remote BLAST.
- Credential-free Bash/Slurm/PBS complete-NR packages and verified safe import.
- Bidirectional NR-to-AF2-to-structure-mining manifests.
- A bilingual NR Mining web view and 65 isolated tests.
- A stage-by-stage NR processing trace, four `2880x1800` desktop captures, and one `780x1688` mobile capture with explicit fixture disclosure and verified temporary-service shutdown.
- Verified MMseqs2 `18.8cc5c` and NCBI BLAST+ `2.17.0` runtimes.

Formal release gates still open:

- A real local NCBI NR hit snapshot requires the user's explicit per-request confirmation.
- At least one real NR candidate must complete AF2 and structural validation.
- Complete NR must run on a server/HPC and return a verified accepted result.

This is not the formal `v0.4.0` Release Notes. The development branch may be pushed, but it must not be merged, tagged, or released.
