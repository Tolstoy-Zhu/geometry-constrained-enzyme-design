# Public Bur01 demo data

`candidates.tsv` contains the seven public fixed-benchmark controls, not production Swiss-Prot candidates.
`demo_manifest.json` records the real Foldseek source run, hashes, software versions and acceptance checks.
TM-align adds separately attributed catalytic mapping; original Foldseek metrics remain unchanged.

No production sequences, weights, database files or credentials are included. Experimental examples are simulated and stored separately in `data/examples/simulated/`.
