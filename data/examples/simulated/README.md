# Simulated measurements / 模拟测量

All rows in `experimental_measurements.csv` are simulated. The candidate IDs are fictitious placeholders, not Bur01 variants or production candidates. The predictor values are selected for hand-checkable arithmetic, not generated by a trained model.

样例均为模拟数据，样品和候选编号仅作占位，不代表Bur01实测或平台生产结果。

- Measured sample means: 10, 20, 30, 40, 50 U/mg.
- Two measurements per sample: mean−1 and mean+1; sample SD = sqrt(2).
- Simulated predictions: 12, 18, 33, 38, 49 U/mg.
- MAE = 2; RMSE = sqrt(4.4); R2 = 1−22/1000 = 0.978.
- Simulated WASE-screen ranks: scores 40, 65, 55, 80, 90; Spearman = 0.9.
- At success threshold ≥30 U/mg and k=3, WASE Top-k hit rate = 2/3.

The blank user template lives in `data/templates/experiment_template.xlsx`. Keep real experiments separate from this directory.
